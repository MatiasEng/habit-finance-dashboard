### 2xx: Success Codes
- 200: Ok 
- 201: Created
- 204: No Content

### 3xx: Redirection
- 301: Moved 
- 302: Found 
- 304: Not Modify

### 4xx: Client Errors
- 400: Bad Request
- 401: Unauthorized
- 403: Forbidden
- 404: Not-Found
- 405: Method Not-Allowed
- 409: Conflict

### 5xx: Server Errors
- 500: Internal Server Error
- 502: Bad Getaway
- 503: Server Unavailable
- 504: GetaWay Timeout
